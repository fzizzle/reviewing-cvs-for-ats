# Intake: ask before editing

The target decides what the CV leads with. Ask these first, in one message. If there's no answer, list your assumptions in the report and don't add new facts.

1. Target role and industry (e.g. "composites R&D internship", "senior B2B marketing manager").
2. Job type and timing: full-time, internship (duration and start date), graduate scheme, contract.
3. Country and city they're applying in, and their right to work if it's relevant.
4. One real advert, if they have one. Build the keyword file from it (see ats-rules.md).
5. Page limit, if they've been told one.
6. For every tool, method, grade, language level or metric you want to add or reword: "Have you used X? Where?" Only confirmed items go on the CV.

## Country conventions (common practice, confirm locally)
| Market | Conventions |
|---|---|
| UK / Ireland | "CV"; no photo, date of birth or marital status; 1 page for graduates, 2 for experienced; A4 |
| US / Canada | "Résumé"; 1 page early career; no photo; US Letter (`@page { size: Letter }`) |
| France | Languages as CEFR levels (A1–C2); internships (stage) need a convention de stage from a school, so show current enrolment first; a French version is often expected; a photo is common but optional |
| Germany / DACH | "Lebenslauf"; tabular and reverse-chronological; photo and date of birth are traditional but optional; certificates matter |
| Other | Ask the person, or check local careers-service guidance |
